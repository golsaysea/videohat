VideoHat

About VideoHat / 关于 VideoHat

Open-source short-form video workflow tool / 开源短视频工作流工具

VideoHat is an open-source web application for preparing Reels, Shorts, TikTok-style caption videos, templates, media pools, batch tables, and export queues.

VideoHat 是一个开源 Web 应用，用于准备 Reels、Shorts、TikTok 风格的字幕视频、模板、媒体池、批量表格和导出队列。

What VideoHat Does / VideoHat 的用途

VideoHat helps users combine video footage, audio, captions, signatures, and reusable style parameters into repeatable video projects.

VideoHat 帮助用户把实拍视频、音频、字幕、署名和可复用样式参数组合成可重复使用的视频工程。

Open Source / 开源项目

The VideoHat source code is publicly available at github.com/golsaysea/videohat.

VideoHat 源代码公开在 github.com/golsaysea/videohat。

Google Drive Integration / Google Drive 集成

When a user connects Google Drive, VideoHat lets the user select their own media files and use them in the media pool. VideoHat requests access only to files selected through the app.

当用户连接 Google Drive 时，VideoHat 允许用户选择自己的媒体文件并加入媒体池。VideoHat 只请求访问用户通过应用主动选择的文件。

Data and Media / 数据与媒体

Local media files are processed in the browser unless the user explicitly uploads them. Google Drive media remains in the user's Google account and is downloaded only when needed for preview or workflow use.

本地媒体文件默认在浏览器中处理，除非用户明确上传。Google Drive 素材保留在用户自己的 Google 账号中，只有在预览或工作流需要时才会下载。
